Entry for the [make.fun bounty "The plan make.fun will carry out in public"](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138): a plan an AI agent can carry out itself to turn $100 into the most money in 30 days.

## The plan

Find firms already paying $500+/month for manual data-entry work (their job ads on Indeed prove the budget), and sell each hiring manager a $199 one-time automation that does that job, built in a day. An agent can do every step itself — search, email, code, and payment by Stripe — with no human in the loop. Expected outcome: 2–4 sales, $400–$800 by day 30.

## Run

`main.py` (Python 3.13, standard library only, no network) writes the plan text to `/output/entry.txt`:

```sh
python3 main.py
```
